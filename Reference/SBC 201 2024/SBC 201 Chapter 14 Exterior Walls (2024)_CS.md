# SBC 201 Chapter 14 Exterior Walls
**Architect critical summary for schematic design**
2024 | SBCNC

> Scope note: This chapter is the **weather envelope** — WRB, covering thickness, vapor retarders, flashing/drainage, and combustible cladding (including MCM, HPL, EIFS). It is **not** the fire-separation-distance or opening-protectives chapter. Exterior-wall **ratings** and **unprotected opening %** are **Table 601 / Table 705.5** and **Table 705.8** (see 1402.4). Energy climate zones named here: IECC / **SBC 601 / SBC 602**. Foam in the wall: **Chapter 26** (including NFPA 285 via 2603.5).

## Regulatory Overview
Every exterior wall must shed weather: WRB (1403.2), flashing (1404.4), drainage, and condensation control (1404.3), unless concrete/masonry, an ASTM E331 barrier wall, or EIFS with drainage. Combustible cladding on Types I–IV is a 10% / 12 m (FRTW 18 m) box plus NFPA 268; MCM/HPL above 12 m need NFPA 285.

## Critical main topics and subtopics

### 1. Weather protection and WRB (1402.2, 1403.2, 1404.2)
Envelope: flashing + **water-resistive barrier** behind the veneer + a **means of draining** water that enters + vapor control per 1404.3.

| Path | When |
|------|------|
| Prescriptive WRB + drainage | Default. ≥ 1 layer: No. 15 felt ASTM D226 Type 1; ASTM E2556 Type I or II; ASTM E331 per 1402.2; or other approved |
| Omit WRB/drainage | Concrete or masonry walls (Chs. 19 / 21) |
| ASTM E331 barrier (no drainage) | Test assembly ≥ **1.2 × 2.4 m**, ≥ **0.3 kN/m²**, ≥ **2 h**, with opening, control joint, wall/eave, sill |
| EIFS | Section 1407; drainage EIFS required on Type V framed walls in **R-1, R-2, R-3, R-4** (1407.4.1), average drainage efficiency ≥ **90%** (ASTM E2273) |

**Table 1404.2** selected minimum covering thicknesses (mm): adhered masonry veneer **6.35**; aluminum siding **0.48**; anchored stone **50.4**; architectural cast stone **62.5**; other anchored masonry **66.67**; plywood with sheathing **7.95**; fiber-cement lap/panel **6.35**; hardboard **6.35**; marble slabs **25.4**; porcelain tile **3.125**; steel **0.37**; structural glass **8.73**; terra cotta anchored **12.7** / adhered **9.525**; vinyl siding **0.88**; wood shingles **9.525**; wood siding without sheathing **12.7** (Note a: wood < **12.5 mm** only over 2304.6 sheathing). Stucco three-coat / two-coat rows in the extract are OCR-incomplete — use the published table, not invented coats. Commentary also cites sheet steel **0.4 mm** and aluminum siding **0.5 mm** in running text.

**SD takeaway:** Framed walls get a continuous WRB and a drainage plane; EIFS on Type V residential is drainage EIFS, not a barrier coat.

### 2. Vapor retarders (1404.3)
Class from Table 1404.3(1); interior VR on frame walls from Tables 1404.3(2)–(3), or approved hygrothermal design. Climate zone: IECC Ch. 3 / **SBC 601/SBC 602**. Class I interior + Class I exterior = approved design. Class II with exterior foam CI: Table 1404.3(4) **and** Class II > **1 perm** (ASTM E96 Procedure B). Table 1404.3(4) in this extract is OCR-destroyed — do not invent R-values.

| Class | Perm (Table 1404.3(1)) | Examples |
|-------|------------------------|----------|
| I | ≤ 0.1 | Sheet polyethylene, nonperforated foil |
| II | > 0.1 and ≤ 1.0 | Kraft-faced batts, paint (as listed) |
| III | > 1.0 and ≤ 10 | Latex or enamel paint (as listed) |

**Table 1404.3(2)** — interior VR on frame walls:

| Climate zone | Class I | Class II | Class III |
|--------------|---------|----------|-----------|
| 1, 2 | NP | NP | Permitted |
| 3 | NP | Permitted | Permitted |
| 4 except Marine 4 | NP | Permitted | See 1404.3(3) |
| Marine 4, 5–8 | Permitted | Permitted | See 1404.3(3) |

Class III in cold zones needs vented cladding or listed CI R-values (Table 1404.3(3); e.g. Zone 4 CI ≥ **R 0.44** over 50×100 mm wall / **R 0.66** over 50×150 mm). Double vapor barriers trap rain — avoid Class I both sides without analysis.

**SD takeaway:** Hot-humid Zones 1–2: no interior Class I/II; cold zones: interior Class I/II and watch CI R-value if using Class III.

### 3. Combustible cladding on Types I–IV (1405)
Not plastics under Ch. 26 (those stay in 2603). Types I–IV:

| Limit | Rule |
|-------|------|
| FSD **≤ 1500 mm** | Combustible covering ≤ **10%** of that exterior wall |
| Height | Combustible covering ≤ **12 m** above grade plane |
| FRTW (2303.2 exterior) | Area not limited at FSD ≤ 1500 mm; height ≤ **18 m** regardless of FSD |
| Type V | No 1405.1.1 area/height cap in this section |

NFPA **268** ignition (exceptions: wood; Table 1404.2 coverings other than vinyl siding; aluminum ≥ **0.5 mm**). FSD ≤ **1.5 m**: no sustained flaming. FSD > 1.5 m: Table 1405.1.1.1.2 (extract example: **9.5 kW/m²** → **30 m** FSD). Furred combustible covering: cavity ≤ **41 mm**, fireblocked per 718 (omit fireblock if NFPA 285 passes — 718.2.6 commentary).

**Combustible WRB (1402.5):** Types I–IV, wall **> 12 m**, combustible WRB → **NFPA 285** (fenestration flashing is not the WRB). Exceptions: WRB is the only combustible and covering is brick/concrete/stone/terra cotta/stucco/steel at Table 1404.2 thickness; or low-heat WRB (ASTM E1354: peak HRR < **150 kW/m²**, total < **20 MJ/m²**, EHC < **18 MJ/kg**; and E84 FSI ≤ 25 / SDI ≤ 450).

**SD takeaway:** Combustible rainscreen on Type I–IV stops at 12 m (18 m FRTW) and 10% of the wall if FSD is under 1.5 m — otherwise NFPA 268/285.

### 4. MCM, HPL, EIFS, foam (1406–1408, 1403.11)
**MCM (1406):** Types I–IV up to **12 m**: 1406.10.1–10.2 (FSI ≤ **25**, SDI ≤ **450**; thermal barrier **12.5 mm** gypsum or NFPA 275). **> 12 m**: also **NFPA 285** (1406.10.3) at max thickness. Type V unrestricted by 1406.11. Foam in the same envelope → **2603**. General MCM FSI ≤ 75 / SDI ≤ 450.

**HPL (1408):** Types I–IV: 1408.10.1–10.4 **or** 1408.11. FSI ≤ 25 / SDI ≤ 450; 12.5 mm thermal barrier; **NFPA 285** (1408.10.4). Alternate: ≤ **12 m** with FSD ≤ **1.5 m** → HPL ≤ **10%** of wall; FSD > 1.5 m → area unlimited.

**EIFS (1407):** ASTM E2568; drainage EIFS on Type V R-occupancy framed walls (90% ASTM E2273); WRB 1403.2 or ASTM E2570; special inspections 1704.2 / 1705.17.

Polypropylene siding (1404.18): unless tested to Ch. 16, wind ≤ **45 m/s**, height ≤ **12 m**, Exposure C. FSD to adjacent building with PP siding ≥ **3 m** (1403.12.2).

**SD takeaway:** MCM or HPL above 12 m on Type I–IV is an NFPA 285 wall assembly, not a shop-drawing cladding swap.

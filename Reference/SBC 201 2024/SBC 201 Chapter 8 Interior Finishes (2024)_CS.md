# SBC 201 Chapter 8 Interior Finishes
**Architect critical summary for schematic design**
2024 | SBCNC

> Scope note: This chapter governs **interior finish, trim, and decorative materials** on new construction (flame spread, smoke, heat/flashover, or flame propagation). It is not occupancy (Ch. 3), construction type (Ch. 6), or means of egress geometry (Ch. 10). **SBC 801** Chapter 8 is the companion for existing buildings and **building contents**. Foam plastic as insulation/finish also runs through **Chapter 26**.

## Regulatory Overview
Wall and ceiling finishes are Class A/B/C by occupancy and location in Table 803.13 — exits are stricter than corridors, which are stricter than rooms. Floors in egress paths pick Class I or II critical radiant flux; foam plastic is not interior finish or trim except via 803.4 / 806.5 / 2604.2.

## Critical main topics and subtopics

### 1. Classes and Table 803.13 (803.1.2, 803.13)
ASTM E84 / UL 723 (smoke-developed **0–450** all classes):

| Class | Flame spread index |
|-------|-------------------|
| A | 0–25 |
| B | 26–75 |
| C | 76–200 |

NFPA 286 meeting 803.1.1.1 (no flashover; peak HRR ≤ **800 kW**; smoke ≤ **1,000 m²**) may be used wherever Class A is required. Thin materials **< 0.9 mm** applied directly to walls/ceilings need not be tested (803.2). Exposed heavy timber (602.4 / 2304.11) is exempt except in interior exit stairs/ramps and exit passageways (803.3).

Selected notes: **a** Class C wainscot ≤ **93 m²** in a grade lobby on a noncombustible base, fireblocked per 803.15.1. **b** Other than I-3, buildings **< 3 stories**: Class B (NS) or Class C (sprinklered) in interior exit stairs/ramps. **c** Use the **space occupancy**, not the building group; waiting areas open to a corridor take the **corridor** row. **d** A-1/A-2/A-3 lobbies ≥ Class B. **e** Assembly OL **≤ 300** may use Class C. **f** “Not applicable” as printed. **g** Class B if the building exceeds two stories. **h** Class C in administrative spaces. **j** Class B wainscot ≤ **1.22 m** in I-3 corridors/EA stairs. **m** Ambulatory-care corridors Class A or B.

**SD takeaway:** Spec finish class by **space type** — unsprinklered exits are typically Class A; open waiting areas inherit the corridor class, not the room class.

### 2. Floor finish (804)
Exception: traditional wood, vinyl, linoleum, terrazzo, and non-fibre resilient coverings. All other floor **coverings**: ASTM D2859 (804.4.1). In stair/ramp enclosures, exit passageways, corridors, and rooms **not** separated from corridors by full-height partitions — minimum critical radiant flux (ASTM E648 / NFPA 253):

| Occupancy of the space | Class | Flux |
|------------------------|-------|------|
| I-1, I-2, I-3 | I | ≥ **0.45 W/cm²** |
| A, B, E, H, I-4, M, R-1, R-2, S | II | ≥ **0.22 W/cm²** |

Sprinklered throughout (903.3.1.1 or 13R): Class II where Class I was required; pill-test / ASTM D2859 where Class II was required.

**SD takeaway:** Carpet in I-occupancy corridors is Class I unless the building is fully sprinklered and you drop to Class II.

### 3. Decorative materials and trim (806)
| Item | Lock |
|------|------|
| Combustible drapes/hangings (other than I-3) | NFPA 701 (or NFPA 289, max **100 kW** @ 20 kW) and ≤ **10%** of the wall or ceiling area attached |
| Group A auditorium, NFPA 13 throughout, installed per 803.15 | ≤ **75%** of aggregate wall area |
| R-2 dorm sleeping/dwelling units, sprinklered 903.3.1 | ≤ **50%** of aggregate wall area |
| B and M fabric partitions hung from ceiling, not floor-supported | 806.4; area **not limited** |
| Window coverings | 10% cap does not apply |
| Noncombustible decorative materials / decorative vegetation | Quantity not limited |
| Trim (not foam) | ≥ Class C; combustible trim (not handrails/guards) ≤ **10%** of that wall or ceiling |
| Floor-wall base ≤ **150 mm** | Test as floor (804.2); ≥ Class II, or Class I if the floor is Class I |
| Pyroxilin / cellulose-nitrate imitation leather | **Prohibited in Group A** (806.6) |
| Occupancy extras | **SBC 801** §§807.5.1–807.5.6 |

Fixed/movable walls, paneling, wall pads covering large areas are **interior finish** (803), not décor.

**SD takeaway:** Keep combustible fabric hangings to 10% of the surface unless the A-auditorium or R-2 dorm exception is clearly met.

### 4. Foam plastic (802.7, 803.4, 806.5)
Not interior **finish** except 2603.9 / 2603.10 / thermal barrier (typically **12.5 mm** gypsum). Not interior **trim** except 806.5 or 2604.2. Commentary to 806.5 (via 2604.2): max **12.5 mm** thick, **200 mm** wide, **10%** of aggregate wall and ceiling, min density **320 kg/m³**, flame spread **75** (Class B); no thermal barrier required for that trim. **SBC 801** §807.4.2.1 further limits foam used as décor, scenery, or exhibit booths (UL 1975) — contents, not this chapter.

**SD takeaway:** Do not leave foam exposed as finish; trim only inside the 12.5 mm / 200 mm / 10% box.

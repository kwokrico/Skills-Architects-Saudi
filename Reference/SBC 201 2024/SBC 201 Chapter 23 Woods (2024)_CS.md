# SBC 201 Chapter 23 Woods
**Architect critical summary for schematic design**
2024 | SBCNC

> Scope note: This chapter governs **wood members and fasteners** (2301.1) — materials, FRTW, and heavy-timber sizes. It is **not** the construction-type chapter. Type III / IV / V wood buildings are set in **Chapter 6**; Type I / II wood exceptions live in **§603.1**. Structural loads: **Chapter 16**. Do not dump fastening or sheathing tables here.

## Regulatory Overview
Wood framing is the default for Types III, IV and V; Type I / II may use wood only where §603 allows it. Schematic locks are FRTW identity (2303.2) and the heavy-timber sizes that make Type IV work (2304.11 / Table 2304.11), not the NDS calcs.

## Critical main topics and subtopics

### 1. What this chapter governs; companion Chapter 6 (2301, 2303.2.9)
Commentary: only Types III, IV or V may be wood buildings; Type I / II wood is via **§603**. Design method (ASD / LRFD / conventional / WFCM / ICC 400) is the engineer’s choice (2302.1). **2303.2.9** sends FRTW in Type I / II to **§603.1**. Commentary to 2303.2.9 lists three 603.1 FRTW uses: nonbearing partitions rated **2 hours or less**; nonbearing exteriors that do not require a fire-resistance rating; roof construction of buildings **not over two stories**.

**SD takeaway:** Pick Type III / IV / V on the Chapter 6 sheet first; this chapter only sizes the wood that type already allows.

### 2. Fire-retardant-treated wood (2303.2)
FRTW is wood impregnated by a pressure process (closed vessel **≥ 350 kPa**, 2303.2.1) or other means during manufacture (2303.2.2). Surface coatings are **not** FRTW. ASTM E84 / UL 723: flame-spread index **≤ 25**; 20-minute continuation, flame front **≤ 3.2 m** beyond burner centerline. Each piece labeled (2303.2.4). Strength values adjusted (2303.2.5). Moisture before use: lumber **≤ 19%**, wood structural panels **≤ 15%** (2303.2.8).

| Exposure | Lock | Section |
|----------|------|---------|
| Weather, damp or wet | Identify as **“Exterior”**; ASTM D2898 rain test, no increase in listed flame-spread | 2303.2.6 |
| Interior | Moisture **≤ 28%** at 92% RH (ASTM D3201); Type A tested per this section | 2303.2.7 |
| Type I / II | **§603.1** only | 2303.2.9 |

**SD takeaway:** Untreated wood is not a Type I / II substitute; FRTW is a labeled 2303.2 product and only where 603.1 lists it.

### 3. Heavy timber — Type IV lock (2304.11, Table 2304.11, §602.4)
Where the code requires heavy timber, members comply with 2304.11.1–2304.11.4. Minimum dimensions: **Table 2304.11** (by roofs or floors supported) **or** 2304.11.2–2304.11.4. Commentary: heavy timber is used in **Type IV** per **§602.4**; the table sizes are about a 1-hour unprotected-wood equivalent, not a structural check. Table 2304.11 in this extract is OCR-garbled on some glued-lam / SCL columns — use the published table for member sizes. Readable running-text locks:

| Element | Minimum | Section |
|---------|---------|---------|
| CLT exterior walls | **100 mm** actual, 2303.1.4 | 2304.11.2.1 |
| Interior walls / partitions | Two layers **25 mm** matched boards, **or** laminated **100 mm**, **or** **1-hour** rated construction | 2304.11.2.2 |
| CLT floors | **100 mm** actual, continuous support-to-support | 2304.11.3.1 |
| Sawn / glulam plank floors | **75 mm** nominal T&G + **25 mm** flooring / **12.5 mm** WSP or particleboard; **or** **100 mm** planks on edge + overlay | 2304.11.3.2 |
| CLT roofs | **75 mm** nominal | 2304.11.4.1 |
| Sawn / WSP / glulam plank roofs | **50 mm** nominal T&G; **or** **32 mm** WSP (exterior glue); **or** **75 mm** planks on edge | 2304.11.4.2 |
| Floors and roofs | No concealed spaces, **or** concealed spaces per **§602.4.4.3** | 2304.11.3, 2304.11.4 |
| Floor-to-wall gap | **≥ 12.5 mm**, covered by wall-fixed molding that does not restrain shrinkage | 2304.11.3.2 |

Table 2304.11 note b (as printed): where protected by approved automatic sprinklers under the roof deck, framing members **≥ 75 mm** nominal in width.

**SD takeaway:** Type IV is a Chapter 6 choice; lock CLT walls/floors at **100 mm** and roofs at **75 mm**, and keep floor/roof cavities either open or 602.4.4.3.

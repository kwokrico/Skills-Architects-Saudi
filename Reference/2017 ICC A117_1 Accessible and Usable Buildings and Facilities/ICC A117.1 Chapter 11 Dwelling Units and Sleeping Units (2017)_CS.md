# ICC A117.1 Chapter 11 Dwelling Units and Sleeping Units (2017)
**Architect critical summary for schematic design**
2017 | ICC

> Scope note: Chapter 11 is technical criteria for Accessible, Type A, Type B, Type C (Visitable), and communication-feature units **only when the administrative authority requires those types** (1101.1). Counts and occupancy triggers are **SBC 201 Chapter 11**; dwellings exception **SBC 1101/1102**. The extract’s user note: Chapters 10 and 11 swapped versus older editions — cite **2017** numbers (**1102**, not 1002). SBC commentary often leaves Type C (1105) unscoped. SBC 201 Chapter 35 lists **ICC A117.1—09**; 2017 new-building CFS/turning in referenced Ch 3–4 is larger — do not treat it as automatically the legal SBC minimum.

## Regulatory Overview
This chapter does not classify occupancy or construction type and does not set how many units of each type are required. Accessible and Type A units are independent-use technical sets; Type B is a reduced-feature set that supplements them; Type C is a visitable entrance-level set; 1106 is a separate communication overlay.

## Critical main topics and subtopics

### 1. Unit-type comparison — route, doors, turning
| Feature | Accessible 1102 | Type A 1103 | Type B 1104 | Type C 1105 |
|---------|-----------------|-------------|-------------|-------------|
| Primary entrance | On AR from public/common; not a bedroom unless only entrance (1102.2) | Same (1103.2) | Same (1104.2) | One entrance on 1105.5 path from street/sidewalk/drive/garage (1105.2) |
| AR through unit | All spaces/elements except unfinished attic/basement (1102.3.1) | Same (1103.3.1) | Same, **plus** one allowed miss: raised or sunken living/dining/sleeping portion, or mezzanine without plumbing or enclosed habitable space (1104.3.1) | Path to 1105.4 spaces only |
| Turning space | All rooms on the AR except non-required toilets and closets/pantries ≤ 48 in (1220 mm) deep (1102.3.2) | Same (1103.3.2) | Not required as a room-wide 304 turn | Not required |
| Doors | Primary + all user-passage: **404** (1102.5) | **404** (1103.5); exterior sliding threshold ¾ in (19 mm) max if 1:2 bevel | Primary: **404** (push/front 48 in (1220 mm) min); interior user-passage clear **31¾ in (805 mm)** — **not** full 404 maneuvering (1104.5) | Clear **31¾ in (805 mm)** (1105.5.3.1) |
| Walking width | 403 | 403 | 403.5 with **existing-style** 180°/90°/passing exceptions (1104.4.1) | 36 in (915 mm) min (1105.5.2.1) |

**SD takeaway:** Do not draw Type B interiors with 404 latch-side clearances; do draw Accessible/Type A units with full 404 at every passage door and a 304 turning space in every habitable room on the AR.

### 2. Toilet, bathing, kitchens
| Feature | Accessible 1102 | Type A 1103 | Type B 1104 | Type C 1105 |
|---------|-----------------|-------------|-------------|-------------|
| Bath | At least one room: **603** + one lav, WC, and tub **or** shower per **604–610** in a single area (1102.11.2); other baths: blocking per 1104.11.1 | At least one adaptable 1103.11.2 (door off fixtures or 305 CFS beyond swing; 606 lav with removable cabinetry; grab-bar **blocking** 1103.11.1); other baths: blocking | Fixtures on accessible levels: **blocking** for future grab bars/seats (1104.11.1); parallel approach at lav/WC permitted; some rooms may be non-accessible | Entrance-level toilet/bath: lav + WC; WC clearances **1104.11.3.1.2**; grab-bar **reinforcement**; not required if entrance level has < 120 ft² (11.2 m²) habitable (1105.4 / 1105.6) |
| Kitchen | **804** (1102.12) | 40 in (1015 mm) min / U-shape 60 in (1525 mm); 30 in (760 mm) work surface with removable cabinetry + 306 (1103.12) | 40 in (1015 mm) / U-shape 60 in (1525 mm); **parallel** CFS at sink (forward 1103 sink optional) (1104.12) | If provided on entrance level: sink + cook + fridge; 40 in (1015 mm) min (36 in (915 mm) if no cooktop/range) (1105.7) |

Accessible-unit beds: ≥5% but not less than one bed in at least one sleeping area; CFS both sides (or one CFS between two beds); open frame; mattress 17–23 in (430–585 mm) AFF; that CFS is also a 906 charging area (1102.15).

**SD takeaway:** Accessible units get grab bars **in place** and 804 kitchens; Type A gets removable bases and blocking; Type B gets 1015/1525 mm kitchen aisles and blocking only — do not mix the three on one typical plan.

### 3. Operable parts, laundry, windows
| Feature | Accessible / Type A | Type B | Type C |
|---------|---------------------|--------|--------|
| Controls | Lighting, panelboards, switches, receptacles, environmental, appliance, plumbing, security/intercom: **309** (1102.9 / 1103.9) | Lighting, switches, receptacles, environmental, panelboards, security/intercom: 309.3 + 1104.1.1 — **not** plumbing/appliance operable-parts 309 (1104.9) | Receptacles and lighting 15–48 in (380–1220 mm) AFF; dedicated, ceiling-fan, floor, and over-counter excepted (1105.8) |
| Laundry | 611 | CFS at each; parallel at top-load; forward or parallel at front-load (1104.10) | — |
| Windows | 506.1 except kitchen and bath (1102.13 / 1103.13) | — | — |

Type B private-residence elevator exception: 48 in (1220 mm) min length × 36 in (760 mm) min width as printed in 1104.7 Exc. Type B platform lift exception: 36×48 in (915×1220 mm) (1104.8 Exc.).

**SD takeaway:** Put Accessible/Type A controls in the 309 reach envelope including plumbing; Type B can omit fixture/appliance 309 but still needs 380–1220 mm switches and receptacles.

### 4. Communication-feature units (1106)
Overlay on whatever mobility type the AHJ assigns.

| Item | Rule | Section |
|------|------|---------|
| Unit smoke | Audible notification per NFPA 72-2016 | 1106.2 |
| Building fire alarm | Wiring extended into the unit near the unit smoke system | 1106.3 |
| Visible appliances | 702; smoke visibles activate on unit smoke; building visibles on building alarm in that portion; same appliances may serve both; not used for other purposes | 1106.4 |
| Primary entrance | Hard-wired doorbell (public-side button); audible in unit; visible-in-bedroom deactivation; visitor ID without opening the door; peepholes 180° min if used | 1106.5 |
| Remote entry comms | If voice is not at the unit door, 1106.6 | 1106.6 |

**SD takeaway:** A comms unit is a strobe/doorbell/180° viewer package — it does not replace Accessible or Type A spatial criteria.

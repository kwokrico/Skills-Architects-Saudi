# ICC A117.1 Chapter 02 Scoping (2017)
**Architect critical summary for schematic design**
2017 | ICC

> Scope note: Chapter 2 is a **scoping disclaimer**, not a count table. ICC A117.1 (2017) supplies technical criteria only; the administrative authority must state how far those criteria apply. In KSA that authority is **SBC 201 Chapter 11** (what / when / how many), with dwellings via SBC 1101/1102 and accessible means of egress via SBC 201 Chapter 10. SBC 201 Chapter 35 lists **ICC A117.1—09**; this CS is the 2017 text as attached — do not treat 2017 dimensions as automatically the legal SBC minimum.

## Regulatory Overview
This chapter does not classify occupancy or construction type and does not set quantities of accessible elements or dwelling-unit types. The administrative authority must supply separate scoping for each occupancy, for new work, alterations, temporary facilities, and existing buildings, and for the types and numbers of dwelling and sleeping units.

## Critical main topics and subtopics

### 1. Who provides scoping (201)
| Item the AHJ must address | In this standard? |
|---------------------------|-------------------|
| Technical how-to for accessible sites, facilities, buildings, and elements | Yes — later chapters |
| Application to each building and occupancy type | **No** — AHJ scoping |
| New construction, alterations, temporary facilities, existing buildings | **No** — AHJ scoping |
| Which site/building elements, and how many of multiples | **No** — AHJ scoping |

**SD takeaway:** Do not invent accessible counts from A117.1; pull percentages and exceptions from SBC 201 Chapter 11, then apply this standard’s technical chapters.

### 2. Dwelling and sleeping unit types named, not counted (202)
Chapter 11 contains technical criteria for five unit sets. The AHJ must specify **types and numbers** required:

| Unit set (Ch 11) | Role in this standard |
|------------------|------------------------|
| Accessible units | Full independent-use technical criteria |
| Type A units | Full independent-use technical criteria |
| Type B units | Reduced-feature set (see 102.1 / 1104) |
| Type C (Visitable) dwelling units | Minimal features (see 102.1 / 1105) |
| Units with communication features | Separate technical set (1106) |

**SD takeaway:** Lock the unit mix (Accessible / A / B / C / comms) in the program from SBC 201 Chapter 11 before planning unit plans; Chapter 2 gives no ratios.

### 3. Review and approval (203)
The administrative authority shall provide an appropriate review and approval process to ensure compliance with this standard.

**SD takeaway:** Treat Baladiya / SBCNC / project AHJ acceptance as the compliance path; A117.1 itself has no permit procedure.

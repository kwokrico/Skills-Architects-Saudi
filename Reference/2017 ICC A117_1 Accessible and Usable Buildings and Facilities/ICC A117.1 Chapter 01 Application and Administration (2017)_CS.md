# ICC A117.1 Chapter 01 Application and Administration (2017)
**Architect critical summary for schematic design**
2017 | ICC

> Scope note: Chapter 1 sets the title, purpose, applicability, conventions, and referenced documents for ICC A117.1 (2017) technical criteria. It is **not** scoping: what, when, and how many accessible elements are required is set by the administrative authority — in KSA, **SBC 201 Chapter 11** (with dwellings via SBC 1101/1102 and accessible means of egress via SBC 201 Chapter 10). SBC 201 Chapter 35 lists **ICC A117.1—09**; do not treat 2017 dimensions in later chapters as automatically the legal SBC minimum.

## Regulatory Overview
This standard does not classify occupancy or construction type; it applies only to sites, facilities, buildings, and elements the administrative authority requires to be accessible (102.2). Chapters 3 through 10 plus Sections 1102, 1103 and 1106 are the independent-use technical criteria; Section 1104 Type B and Section 1105 Type C are reduced-feature unit sets used only if the authority requires them (102.1).

## Critical main topics and subtopics

### 1. Purpose and applicability (102)
| Set | What it does | When it applies |
|-----|----------------|-----------------|
| Ch 3–10; 1102, 1103, 1106 | Technical criteria so a person with a physical disability can independently get to, enter, and use the site, facility, building, or element | Where the AHJ requires accessibility |
| 1104 Type B | Intended to be consistent with HUD Fair Housing Accessibility Guidelines; **supplements, does not replace**, Accessible or Type A units | Only if AHJ scopes Type B |
| 1105 Type C | Minimal accessibility features for one- and two-family dwelling units and townhouses **not** covered by HUD FHAG | Only if AHJ scopes Type C |
| Ch 3–10 | Sites, facilities, buildings, and elements required to be accessible | AHJ scoping (102.2) |
| Ch 11 | Dwelling units and sleeping units | AHJ scoping (102.2) |

**SD takeaway:** Lock unit **type** (Accessible / A / B / C / comms) from SBC 201 Ch 11 before applying A117.1 dimensions; Type B never substitutes for Accessible or Type A.

### 2. Human factors and alternatives (103–104)
| Rule | Section |
|------|---------|
| Criteria are based on **adult** body sizes and abilities, and on **children** only where a section specifically notes children’s use | 103.1 |
| Alternative designs, products, or technologies are permitted if they provide equivalent or greater accessibility **and** the adopting administrative authority approves equivalency | 104.1 |

**SD takeaway:** Use adult clearances as the default plan module; switch to children’s-use rows only where the later chapter labels the space for ages 12 and under.

### 3. Conventions that change drawings (105)
| Convention | Rule | Section |
|-----------|------|---------|
| Conflict | Specific criteria override general criteria | 105.1 |
| Percentages / ratios | Rounding **down** permitted for values less than one half | 105.2 |
| Tolerances | Conventional industry tolerances apply, **except** where the requirement is a min–max range | 105.3 |
| Figures | Informational only unless the text specifically states otherwise | 105.4 |
| Floor | “Floor” / “floor surface” = finish floor or ground surface | 105.5 |
| Cross-refs | A cited section includes all its subsections unless stated otherwise | 105.6 |

**SD takeaway:** Do not treat figure graphics as the legal dimension; pull numbers from the numbered clause, and do not apply construction tolerance to a published min–max range.

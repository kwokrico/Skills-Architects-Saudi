# Agent instructions — Skills Architect Saudi

## Professional skill activation

When the user's request involves **Saudi (KSA) architecture**, building codes (**SBC**), **SCD** / fire approvals, **SBPS** / Baladiya permits, **Mostadam**, giga-project authorities (NEOM, RSG, DGDA), desert-climate detailing, or KSA contract delivery (**FIDIC**-heavy practice):

1. Read and follow [`saudi-architect-master/SKILL.md`](saudi-architect-master/SKILL.md) (master router).
2. Apply [`saudi-architect-master/references/compliance.md`](saudi-architect-master/references/compliance.md) halt rules before regulatory conclusions.
3. Route deep topics via the master decision tree or `load_saudi_sub_skill` (see [`saudi-architect-master/main.py`](saudi-architect-master/main.py)); dispatch to `subskills/<slug>/<slug>.md` for the selected module.
4. Use [`saudi-architect-master/references/domain_terms.json`](saudi-architect-master/references/domain_terms.json) when acronyms are ambiguous.
5. Prefer [`saudi-architect-master/references/templates/deliverables.md`](saudi-architect-master/references/templates/deliverables.md) (catalog T-01–T-24) for formal memos, logs, and stage artifacts.

**Do not** load all sub-skills for routine questions answerable from the master quick reference.

**Verification:** See [`saudi-architect-master/VERIFICATION.md`](saudi-architect-master/VERIFICATION.md) and [`saudi-architect-master/evals/evals.json`](saudi-architect-master/evals/evals.json).

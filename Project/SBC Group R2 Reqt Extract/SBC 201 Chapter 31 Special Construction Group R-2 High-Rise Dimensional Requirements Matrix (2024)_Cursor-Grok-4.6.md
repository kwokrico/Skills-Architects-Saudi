- **Project basis:** Riyadh, Saudi Arabia; Group R-2 residential high-rise; an occupied floor is stated to be more than 23 m above the relevant reference level.

- **Code/source basis:** SBC 201 (2024), Chapter 31, source file `Reference\SBC 201 2024\source_reference\Chapter_31 — SPECIAL CONSTRUCTION.txt`.
- **Extraction audit:** Skill extract. Project-use rows follow the chapter-extract row contract (noun-phrase checks, bold SI values, building-language triggers, named exceptions, check-specific actions). Internal inventory: **121** independently checkable numeric records (**60** Verified, **61** Verify source). Unresolved OCR is listed in the register and is not a design-release value.
- **Model:** Cursor Grok 4.6.
- **Prepared:** 2026-08-27.
- **Status:** Source-only architectural advisory matrix for design coordination. It is not a stamped compliance statement, structural design, SCD NOC, SBPS approval, legal opinion, or permission to construct.
- **Outbound-source rule:** No value in this matrix has been imported from Chapters 7, 10, 11, 15, 16, 24, 26 or 32; Sections 504.3, 506, 705, 707, 716 or 903.3.1.1; Table 705.5; SBC 401, 501, 701, 801, 901 or 1401; ASCE 55; TIA-222; NFPA 70; ISO 668 / 1496-1 / 6346; CST-GUIDE-101.3-24; commentary examples; or the existing chapter summary. Where Chapter 31 sends the user elsewhere, this matrix records the dependency without supplying the outbound value.

### Scope and assumptions

1. Group R-2 and high-rise status are project statements, not independently verified classifications.
2. The exact Riyadh AHJ/permit pathway, project stage, fire-strategy status and SCD NOC status are unconfirmed; therefore this matrix does not conclude compliance.
3. Automatic sprinkler protection is not selected. Walkway travel-distance and several 3104.5 options cite **Section 903.3.1.1** only. NFPA 13 versus 13R is not assumed.
4. Pedestrian links, amenity pools, rooftop or BIPV solar, entry canopies/marquees, terrace/atrium membranes, temporary event structures, rooftop telecom and vehicular gates are unconfirmed.
5. Greenhouse, relocatable-building, flood-hazard public-restroom and intermodal-container programs are not assumed. Those clauses are inventoried for coverage and omitted from lead tables.
6. Section 3114 appears in the extract only as “Not applicable to KSA”; no 3114 code values are adopted.
7. 3104.8 total-width text and Table 3115.8.5.3 are OCR-unresolved. Affected inventory records are **Verify source**.

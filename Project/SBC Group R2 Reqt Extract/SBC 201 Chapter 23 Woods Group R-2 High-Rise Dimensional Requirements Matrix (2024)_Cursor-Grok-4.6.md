- **Outbound-source rule:** No value in this matrix has been imported from Section 603.1, Table 601, Chapter 6 construction-type hours, Chapter 8 flame-spread classes, Chapter 16 loads, Chapter 17 special inspections, Section 1202 ventilation rates, Sections 2111 / 2113, SBC 301, SBC 303, AWC NDS, AWC SDPWS, AWC WFCM, AWC PWF, TPI 1, ICC 400, commentary examples, figure notes, bibliography years, or the existing chapter summary. Where Chapter 23 sends the user elsewhere, this matrix records the dependency without supplying the outbound value.

### Scope and assumptions

1. Group R-2 and high-rise status are project statements, not independently verified classifications.
2. The exact Riyadh AHJ/permit pathway, project stage, fire-strategy status and SCD NOC status are unconfirmed; therefore this matrix does not conclude compliance.
3. Type of construction is unconfirmed. A Group R-2 high-rise is typically Type I (or II). This chapter sizes and qualifies wood members; it does not assign construction type. Type I/II wood use is limited by **603.1**, which is not reprinted here.
4. Automatic sprinkler protection is not selected. Chapter 23 does not branch on NFPA 13 versus 13R except Table 2304.11 note b (heavy-timber roof-member width under an approved sprinkler), which is **Verify source** / Conditional Type IV.
5. Mixed-use podium, storey count, wood sleepers, wood balcony framing, FRTW partitions, millwork and mass timber are unconfirmed.
6. Conventional light-frame Section **2308** is charged in this extract as **deemed inapplicable to Saudi Arabia**. WFCM (2309) is limited to Risk Category I or II buildings inside the WFCM’s own size and load limits and is not a high-rise wood-frame method.
7. Appended fastening, sheathing-span, diaphragm and shear-wall tables are concatenated OCR. No reconstructed table cell is adopted as a design-release value.

2. Do not use **Verify source** rows, including reconstructed fastening, sheathing, diaphragm, shear-wall or Table 2304.11 body cells, as design-release values.

4. Do not import Chapter 8 interior-finish classes, Chapter 16 loads, Chapter 12 ventilation ratios, NDS/SDPWS stresses, or WFCM dwelling tables.
5. Do not treat General Comments (only Types III/IV/V as wood buildings) or commentary examples as numbered code cells.
6. Do not use Section 2308 as a KSA prescriptive wood-frame path.
7. Omit wood-frame fastening, sheathing-wind, diaphragm and shear-wall tables from issued architectural drawings unless the gap register opens a wood podium or Type IV LFRS.

## 1. Document metadata and use limitation

- **Project basis:** Riyadh, Saudi Arabia; Group R-2 residential high-rise; an occupied floor is stated to be more than 23 m above the relevant reference level.
- **Deliverable tier:** Project-use matrices in Sections 4–10 (design-check rows, not pasted inventory), plus a coverage summary and unresolved-source register. The full row inventory is not published.
- **Code/source basis:** SBC 201 (2024), Chapter 1, source file `Reference\SBC 201 2024\source_reference\Chapter_01 — SCOPE AND APPLICABILITY OF THE GENERAL SAUDI BUILDING CODE.txt`.
- **Extraction audit:** Skill extract. Project-use rows follow the chapter-extract row contract (noun-phrase checks, bold SI values, building-language triggers, named exceptions, check-specific actions). Internal inventory: **29** independently checkable numeric records (**27** Verified, **2** Verify source). Unresolved OCR (missing 101.4 plumbing subsection, 109.6 parenthetical refund cap, flattened Table 1-A) is listed in the register and is not a design-release value.
- **Model:** Cursor Grok 4.6.
- **Prepared:** 2026-08-27.
- **Status:** Source-only architectural advisory matrix for design coordination. It is not a stamped compliance statement, permit, SCD NOC, SBPS approval, legal opinion, or permission to construct.
- **Outbound-source rule:** No value in this matrix has been imported from SBC 301–313, SBC 401, SBC 501, SBC 601/602, SBC 701/702, SBC 801, SBC 901, SBC 1001, SBC 1101/1102, SBC 1201, Chapter 9, Chapter 16, Section 1603, Section 3103, NFPA 70, Appendix A or B, commentary examples, bibliography years, or the existing chapter summary. Where Chapter 1 sends the user elsewhere, this matrix records the dependency without supplying the outbound value.

### Scope and assumptions

1. Group R-2 and high-rise status are project statements, not independently verified classifications.
2. The exact Riyadh AHJ/permit pathway, Code Compliance Department (CCD) office, project stage and SCD NOC status are unconfirmed; therefore this matrix does not conclude compliance.
3. Automatic sprinkler protection, mixed-use podium, amenity program, storey count and construction type are unconfirmed. Chapter 1 does not branch on NFPA 13 versus 13R.
4. Appendices are not part of the code unless specifically adopted (101.2.1). Appendix A (qualifications) and Appendix B (appeals) are not treated as adopted here.
5. The 101.2 exception that sends detached one- and two-family dwellings and townhouses **not more than three stories** to **SBC 1101/1102** does not reclassify this R-2 high-rise. Section **101.4.9** names those residential volumes as companions; it does not move the tower off SBC 201.
6. A numbered **101.4.5** plumbing charging paragraph is missing from the attached extract (101.4.4 jumps to 101.4.6). Commentary text naming SBC 701/702 is not adopted as a code cell.

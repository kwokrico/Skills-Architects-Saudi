### Scope and assumptions

1. Group R-2 and high-rise status are project statements, not independently verified classifications.
2. The exact Riyadh AHJ/permit pathway, project stage, fire-strategy status and SCD NOC status are unconfirmed; therefore this matrix does not conclude compliance.
3. Type of construction is unconfirmed. A Group R-2 high-rise is expected to be Type I or II unless the project elects mass timber (Type IV-A/B/C). Type III, Type V and Type IV-HT are not treated as the tower shaft.
4. Automatic sprinkler protection, mixed-use podium, storey count and fire separation distance are unconfirmed. Sprinkler branches that appear in this chapter are shown, not assumed.
5. Table 601 in the attached extract is concatenated. No hourly cell and no table note a–g is adopted from memory, commentary or the chapter summary.
6. Commentary Figure 601 roof-clearance examples, Table 601 Note b **6 m** roof-unprotected relief, and commentary hour grids (IA **3 h** / IB **2 h** / IIA **1 h** / IIB **0 h**) are not adopted. The **6 m** that is numbered code is 603.1 Item 1.3 Exception 1 only.

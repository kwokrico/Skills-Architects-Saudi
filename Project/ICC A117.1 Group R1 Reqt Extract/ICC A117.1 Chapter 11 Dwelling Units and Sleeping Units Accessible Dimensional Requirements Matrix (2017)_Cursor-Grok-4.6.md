# ICC A117.1 Chapter 11 Dwelling Units and Sleeping Units — Accessible Dimensional Requirements Matrix (2017)

## 1. Document metadata and use limitation

- **Project basis:** Mixed-use tall building containing Group R-1 (hotel) with Group R-2 residential sharing podium, parking and routes. An occupied floor is stated to be more than 23 m above the relevant reference level. This matrix filters ICC A117.1 Chapter 11 for **Accessible units** (Section 1102).
- **Unit type:** Accessible (1102). Type A, Type B and Type C interiors are omitted from this file.
- **Deliverable tier:** Project-use matrices in Sections 4–14 (design-check rows, not pasted inventory), plus project-use controls, a coverage summary and an unresolved-source register. The full row inventory is not published.
- **Code/source basis:** ICC A117.1 (2017), Chapter 11, source file `Reference\2017 ICC A117_1 Accessible and Usable Buildings and Facilities\source_reference\Chapter_11 — DWELLING UNITS AND SLEEPING UNITS.txt`. Companion numbers inlined from the attached 2017 Chapter 1–10 `source_reference` extracts where 1102 charges those sections.
- **Extraction audit:** Internal inventory: **241** independently checkable numeric records (**218** Verified, **23** Verify source). Unresolved OCR/flattened tables are listed in the register and are not design-release values.
- **Inspecting model:** Cursor Grok 4.6.
- **Prepared:** 2026-08-28.
- **Status:** Source-only architectural advisory matrix for design coordination. It is not a stamped compliance statement, accessibility consultant report, SCD NOC, SBPS approval, legal opinion, or permission to construct.
- **Scoping companion:** Counts, which units, and where Accessible units are required are **SBC 201 Chapter 11**. This file is technical geometry only.
- **Edition gap:** SBC 201 Chapter 35 lists **ICC A117.1—09**. Charging SBC 1102.1 has no year. This extract is **2017**. 2017 new-building clear floor space, turning space and door manoeuvre are larger than 2009. **Do not treat 2017 millimetres as the legal SBC minimum.** Do not back-fill 2009 values from memory.

### Scope and assumptions

1. Group R-1 hotel Accessible guestrooms are the Direct typical. R-2 Accessible units, if provided, use the same 1102 technical set.
2. New construction is assumed. Existing-building dimensions are Conditional and are never mixed onto a Direct row with the 2017 new-building option set.
3. AHJ, SCD NOC, guestroom count and kitchenette provision are unconfirmed.
4. Type C (1105) is omitted. Communication features (1106) are a Conditional overlay, not a substitute for 1102 mobility geometry.
5. Children’s toilets (604.11), urinals (605), public toilet compartments (604.9–604.10), drinking fountains (602) and recreational facilities (Chapter 10) are omitted unless 1102 names them.
6. FIGURE captions are dependencies, not values. Flattened `<table>` blobs are not reconstructed as Verified cells.
7. ASME A17.1, BHMA A156, NFPA 72 and AAMA 513 are named companions only; unstated values are not imported.

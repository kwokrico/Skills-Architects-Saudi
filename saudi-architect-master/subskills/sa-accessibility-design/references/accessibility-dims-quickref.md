# Accessibility dimensions quick-ref (A117.1-2017 citations)

Advisory practice table for `sa-accessibility-design`. Values are **paraphrased working figures** commonly aligned with ICC A117.1-2017 (imperial criteria converted to mm). **Always verify** against:

1. Licensed PDF: `reference/private/icc-a117.1-2017.pdf`
2. Project **SBC 1001** / adopted Chapter 11 text
3. AHJ / MoMRAH / giga-project guidelines

Do not treat this table as stamped compliance. See [`../../../references/compliance.md`](../../../references/compliance.md).

## Building blocks and routes

| Topic | Working figure | Cite (A117.1) | KSA / skill note |
|-------|----------------|---------------|------------------|
| Accessible route clear width | ≥ **915 mm** (36 in) | 403 | Matches skill “915 mm” route width |
| Passing space (where required) | **1525 × 1525 mm** | 403 | Coordinate with long corridors |
| Turning space (circular) | **1525 mm** diameter | 304 | Or compliant T-shaped turn |
| Clear floor space (typical) | **760 × 1220 mm** | 305 | Orient for forward or parallel approach |
| Headroom along route | ≥ **2030 mm** (80 in) | 307 | Skill flags ~2050 mm — use stricter of code/AHJ |
| Protruding object (post-mounted) | Limit protrusion into route | 307 | FHC, thermostats, signage |
| Change in level (vertical) | Small rises per 303; ramps/elevators beyond | 303 | Avoid “threshold creep” at finishes |
| Door clear opening | ≥ **815 mm** (32 in) | 404 | Check leaf, stops, and hardware |
| Threshold at door | Prefer ≤ **13 mm**; bevel rules apply | 404 / 303 | Skill “20 mm trap” — treat 20 mm as failure risk; verify SBC limit |
| Maneuvering clearance (latch pull side, front approach) | Often **450–600 mm** latch-side + depth | 404 | Vestibules / sand mats must not steal clearance |

## Ramps and stairs

| Topic | Working figure | Cite (A117.1) | KSA / skill note |
|-------|----------------|---------------|------------------|
| Max running slope | **1:12** | 405 | Steeper only if standard exceptions apply (rare on new work) |
| Cross slope | ≤ **1:48** | 405 | Drainage vs accessibility conflict in desert detailing |
| Max rise between landings | **760 mm** (30 in) | 405 | At 1:12 ≈ **9.14 m** horizontal run — skill “landings every 9 m” |
| Landing size (typical) | ≥ **1525 mm** in direction of travel | 405 | Longer landings at doors / switches |
| Handrail height | Roughly **865–965 mm** | 505 | Continuous, returns, clearance from wall |
| Stair nosing / tread-riser | Per 504 | 504 | Contrast and open-riser rules as scoped |

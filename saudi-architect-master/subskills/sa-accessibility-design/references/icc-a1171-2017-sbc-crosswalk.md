# ICC A117.1-2017 ↔ SBC accessibility crosswalk

Advisory only. Verify every cited dimension and scoping rule against the **licensed** ICC A117.1-2017 PDF (`reference/private/icc-a117.1-2017.pdf`) and the project **SBC edition / AHJ**. Do not assert compliance without those checks — see [`../../../references/compliance.md`](../../../references/compliance.md).

**Editions:** ICC A117.1-2017 (Accessible and Usable Buildings and Facilities). KSA practice in this suite is framed as **SBC 1001** (accessibility / universal design). Where the SBC building volume uses an IBC-style **Chapter 11** accessibility chapter, treat that chapter as the scoping host that points into A117.1 technical criteria — confirm the project’s adopted edition before locking design.

**Content rule:** This file is a section map and short paraphrase for skill routing. It is **not** a substitute for the copyrighted standard. Do not paste verbatim ICC text into the skill pack.

## Hotspot crosswalk (skill → A117.1)

| Skill / SBC 1001 focus | Typical A117.1 sections | Design note (paraphrase) |
|------------------------|-------------------------|---------------------------|
| Continuous accessible path (site → entrance → floors) | Ch. 2 scoping; **402–403** accessible routes / walking surfaces | Unbroken route; confirm exceptions and multi-story scoping with AHJ |
| Clear width / passing / headroom | **403**; protruding objects **307** | Route width and overhead clearance; coordinate FHC / thermostats / signage |
| Changes in level / thresholds | **303**; door thresholds under **404** | Finish transitions at balconies/entries often fail inspections |
| Doors and maneuvering clearances | **404** | Pull-/push-side clearances; sand lobbies and mats must not steal latch-side space |
| Ramps, landings, handrails | **405**; handrails **505** | Max running slope; level landings; intermediate landings on long runs |
| Curb ramps / ROW interface | **406**; site elements Ch. 5 | Plot-to-sidewalk grade breaks; municipal ROW levels |
| Elevators / LULA / platform lifts | **407–410** | Car size, door timing, control heights; align with SCD evacuation strategy |
| Stairs (where on accessible route or required) | **504**; handrails **505** | Nosing, contrast, handrail continuity |
| Parking / passenger loading | **502–503** | Stall size, access aisle, route to entrance |
| Toilet / bathing rooms | **603–610** (esp. **604** WC compartments) | Transfer clearances, grab bars, turning space |
| Lavatories / sinks | **606** | Knee/toe clearances and reach |
| Turning / clear floor space | **304–306** | Turning circle or T-turn; clear floor at fixtures |
| Reach ranges / operable parts | **308–309** | Controls, call buttons, outlets |
| Signs / Braille / tactile | **703** | Arabic/English wayfinding still requires AHJ / MoMRAH practice |
| Detectable warnings | **705** | Curb ramps, hazardous vehicular areas as scoped |
| Dwelling / hotel sleeping units | Ch. **10** | Unit type and quantity from scoping (SBC / project brief) |

## Workflow

1. Confirm AHJ, occupancy, and SBC edition.
2. Scope with SBC 1001 / Chapter 11 host requirements.
3. Detail technical geometry against A117.1 sections above (licensed PDF).
4. Record gaps in T-18 Accessibility compliance statement ([`templates/deliverables.md`](../../../references/templates/deliverables.md)).

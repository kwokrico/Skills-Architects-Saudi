# SCD licensing and closeout checklist (reference)

Use with `sa-scd-licensing-compliance`.

## Pre-inspection

- [ ] Stamped fire strategy and latest NOC
- [ ] Material submittal log (life safety) with SASO / SCD status
- [ ] Contractor Civil Defence licenses for installers
- [ ] Maintenance contracts for active systems

## Testing

- [ ] IST schedule and cause-and-effect approved
- [ ] Smoke extract / pressurization test procedures
- [ ] As-built egress matches approved SBPS set

## Occupancy blockers

- Unsealed shaft penetrations
- Egress changes without SBPS amendment
- Failed integrated systems test

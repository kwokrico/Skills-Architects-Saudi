# Traffic submission types — KSA municipalities

Use with `sa-site-establishment`. Confirm current requirements with project AHJ.

---

## Planning vs construction (do not conflate)

| Type | When | Purpose |
|------|------|---------|
| **Traffic Impact Study (TIS)** | Masterplan / large scheme planning | Trip generation, junction capacity |
| **Construction TMP** | Mobilisation / main works | Lane closure, haul route, pedestrian diversion |
| **Event / temporary closure** | Crane lifts, oversail | Short-duration road occupation |

---

## Typical TMP contents

1. Site location plan and haul route map
2. Phasing diagrams (before / during / after)
3. Pedestrian diversion and accessibility (SBC 1001 on public realm)
4. Bus stop / taxi rank relocations
5. Signage and lighting plan
6. Emergency vehicle access maintained
7. Contact details and 24h emergency number

---

## Riyadh-specific interfaces

| Interface | Trigger |
|-----------|---------|
| **Riyadh Metro ROW** | Crane within 20 m of alignment; bridge works |
| **King Fahd Road / arterials** | Extended lane closures — early engagement |
| **Diriyah / heritage buffers** | Restricted hours; aesthetic hoarding standards |

---

## Programme risks

- TMP approval: allow **2–6 weeks** municipal review (varies by city).
- Ramadan: reduced processing; avoid critical crane dates in first week.
- Coordinate TMP windows with `sa-construction-programme` look-ahead.

---

## Outputs

- TMP drawing set index
- Municipality approval letter / permit number
- Interface note to hoarding design (sight lines, pedestrian width)

Cross-link: `sa-spatial-planning` for planning-stage TIS scope.

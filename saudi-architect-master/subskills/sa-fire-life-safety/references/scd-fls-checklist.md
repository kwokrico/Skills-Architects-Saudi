# SCD / FLS coordination checklist (reference)

Use with `sa-fire-life-safety`. Advisory only — stamped fire engineer and SCD govern outcomes.

## Design development

- [ ] Stamped fire strategy scope agreed with AOR
- [ ] Compartmentation and egress on coordinated sheets
- [ ] Smoke management concept aligned with MEP
- [ ] SASO-listed equipment schedule started

## Submission

- [ ] SBC 501 compliance statement from fire engineer
- [ ] Cause-and-effect matrix outline for IST planning
- [ ] Civil Defence consultant license on fire drawings

## Site / closeout interface

- [ ] Penetration sealing specification referenced
- [ ] As-built amendment process defined if site changes occur

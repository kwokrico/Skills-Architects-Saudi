# SBC / SBPS submission checklist (reference)

Use with `sa-building-codes`. Verify edition and AHJ before citing.

## Pre-submission

- [ ] AHJ confirmed (municipality vs special authority)
- [ ] Occupancy classification per SBC 201 / 801
- [ ] Construction type and height limits checked
- [ ] Unified Statement of Compliance (architecture + structure + fire aligned)

## Core packages

- [ ] Architectural layouts (scaled, dated, revision log)
- [ ] SBC compliance matrix by chapter
- [ ] Local consultant / AOR portal credentials for SBPS
- [ ] Preliminary SCD clearance status (if applicable at stage)

## Common rejection drivers

- Fire narrative disconnected from architectural plans
- Occupancy load mismatch between disciplines
- Incomplete energy / accessibility chapters where triggered
